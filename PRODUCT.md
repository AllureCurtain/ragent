# NexusQA - finesse brief

register: product
one-liner: An Agentic RAG workspace for evidence-backed chat, knowledge operations, retrieval diagnostics, and ingestion administration.

## Users & context

Knowledge workers use chat to get grounded answers and inspect sources. Administrators spend long desktop sessions ingesting documents, configuring retrieval and intent behavior, and tracing failures. Mobile is a compact chat and monitoring surface, not a squeezed desktop console.

## Brand personality

soul: calm precision + evidence-led
voice: direct, compact, operational

## Locked dials (project defaults)

SOUL: 6   SPECTACLE: 2   DENSITY: 8

## Visual lock

accent: mineral teal (#176C6B), with clay (#C4633F) reserved for a secondary data series
theme: light tinted content with a hue-matched dark navigation rail; optimized for long operational sessions
type: Manrope for readable UI hierarchy, Chinese system sans fallbacks for glyph quality, JetBrains Mono only for identifiers and code

## Anti-references (must NOT look like)

- first-order: no AI-purple or generic platform-blue glow, gradient text, floating orbs, or decorative glass cards
- second-order: no Linear clone, terminal-green dark mode, or oversized editorial typography used as an anti-SaaS reflex
- no uniform white-card gallery, rainbow status palette, or motion that does not explain state

## Notes

- Preserve product naming, routes, API contracts, data semantics, and established task flows.
- Product motion is feedback-only: reveal hierarchy, state transitions, streaming status, and chart updates.
- All motion must have a reduced-motion terminal state.
- Admin pages prioritize scanability and completion; chat prioritizes focus, source trust, and uninterrupted reading.
